# Facility photos

The detail page uses each facility's `imagePath` in `src/assets/data/facilities.json`. Add a real photo of map number `N` as `N.jpg` here to display it. Photos should show the named facility, not a campus overview or an unrelated building. Until a photo exists, the detail page says that a photo is unavailable.

`entrance.jpg` shows the NEUST Sumacab entrance provided in the request. Source: [NEUST campus image](https://neust.edu.ph/wp-content/uploads/2022/04/SUMACAB-1.jpg) (official university site).
